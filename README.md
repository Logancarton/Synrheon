**Synrheon** — from Greek *syn* (“together”) + *rheō* (“to flow”). Roughly: **“flows coming together.”** 

# Synrheon: A Brain-Inspired Recursive Cognitive Architecture for Persistent Artificial Intelligence

This repository is the canonical home for Synrheon.

Synrheon is being developed as a persistent, recursive cognitive system with explicit internal state, computational time, memory, sparse activation, hierarchical retrieval, learning, abstraction, and eventually autonomous continuation.

The current implementation priority is **Stage 0B — Observable Organism Harness**: establish a thin runtime and development UI so later cognitive mechanisms can be stimulated, stepped, observed, traced, and tested through the running organism rather than inferred only from pass/fail tests.

See the full repository documentation for architecture, current status, signal flow, plain-English code guidance, experiments, decisions, research, and development workflow.
